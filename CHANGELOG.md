# Changelog

## 2.1

### Added

- Details pane on the right of the results, as on Windows 11: the selected result in large (with a preview for images and documents), Open, and the other actions shown below it: open file location, copy path, the app's own actions, edit the application, manage it in Discover. For an app, its recent files are listed too.
- "Best match" at the top of the results.
- **"Magnifier only" mode** in the taskbar (setting): the magnifier replaces the search box, with the same hover frame as the Start button. One click opens the window, and the typing area appears in the bottom bar, with the text "Type here to search" like Windows 11.
- **Gear** at the top right of the window, on the home page and in results: search settings and Fenestra Search configuration.
- **Back arrow** on the left of the filters, as in Menu 11's search.
- Result **categories can be collapsed**, with a blue line and an arrow.
- About window with the Fenestra logo, in the "···" menu of the bottom bar.
- The window size follows **Fenestra Menu 11**: the "Menu size" setting is read, so the window is 604 px (small), 725 px (automatic) or 796 px (large) wide, with the same height as the Menu 11 window (820 px, never taller than the free height of the screen). Without Menu 11, the width is automatic.
- Two languages: Brazilian Portuguese and Traditional Chinese (14 languages in total, with English).
- Fluent UI System Icons MIT license file.
- **Tooltips** on the gear and on the "···" button.

### Changed

- The search window is placed like the start menu: centred on the screen, 10 px above the panel, with **four rounded corners** like Menu 11; its bottom bar has the same height as the start menu's and goes to the edges of the window.
- Filter capsules have the same size as in Menu 11, and are left-aligned after the back arrow.
- "Quick searches" can no longer be collapsed.
- Home page and results are 18 px from the window edges, the results scroll bar is 8 px from the right pane, and the home page content moves down 10 px to leave room for the gear.
- The selected result has the same background as the hover on the home page.
- Code comments are now in English, and all files have the Fenestra Search header.

### Fixed

- The gear and "···" menus no longer stay open when the window is closed and opened again.

### Tested on

Fedora, Kubuntu, openSUSE and Manjaro.

# Changelog

## 2.1.1

### Fixed
- Updates now go through Discover, with your other updates. On distributions without Discover, such as Manjaro, updates have to be done manually.

### Improved
- Search results, like Windows 11: the best match stays framed so the right-hand pane always has something to show, the row under the mouse gets its own frame, and the mouse no longer takes the selection.

## 2.1

### Added
- Details pane on the right of the results, as on Windows 11: the selected result in large (with a preview for images and documents), Open, open file location, copy path, the app's own actions, manage it in Discover, and its recent files.
- "Best match" at the top of the results.
- "Magnifier only" mode in the taskbar (setting): the magnifier replaces the search box. One click opens the window, and the typing area appears in the bottom bar, like Windows 11.
- Same window as Fenestra Menu 11: centred on the screen, 10 px above the panel, four rounded corners, same height (820 px, never taller than the screen). The width follows the "Menu size" setting: 604 px (small), 725 px (automatic) or 796 px (large). Without Menu 11, the width is automatic.
- Gear (search settings and Fenestra Search configuration), back arrow on the left of the filters and collapsible result categories, as in Menu 11's search.
- Languages: English, French, German, Spanish, Italian, Portuguese (Portugal), Portuguese (Brazil), Dutch, Polish, Russian, Turkish, Japanese, Simplified Chinese and Traditional Chinese.

### Fixed
- The gear and "···" menus no longer stay open when the window is closed and opened again.

### Tested on
Fedora, Kubuntu, openSUSE and Manjaro, in light and dark themes.
